# Palette AI

Palette AIは、ベースカラー・メインカラー・アクセントカラーを自動生成するAIツールです。
配色の知識がない方でも、簡単に生成することができます。

🌐 URL: https://palette-ai.jp

### Screenshots

![](https://images.microcms-assets.io/assets/ab7ffc338c5f4b81bc39d8d51713e928/9cccf5d555ac4c98aa13efb5e2efba58/screenshots.png)

### Features

- AIを活用した配色の自動生成
- Auth.js（Googleプロバイダ）を活用したユーザー認証
- Prisma・Supabaseを活用したデータベース管理
- Stripeによる有料プランの決済
- microCMSを活用したお知らせ配信
- ReSendを活用したお問い合わせ
